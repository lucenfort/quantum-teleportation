# Teletransporte Quântico

Simulação de emaranhamento quântico e protocolo de teletransporte usando Qiskit.

## Recursos

- **Estados de Bell**: Geração e análise de quatro estados emaranhados maximais
- **Protocolo de Teletransporte**: Implementação completa de transferência de estado quântico
- **Visualização**: Resultados gráficos de alto contraste

## Início Rápido

```bash
pip install -r requirements.txt
python src/main.py
```

## Estrutura do Projeto

```
src/
  ├── bell_states.py           # Geração e visualização de Estados de Bell
  ├── quantum_teleportation.py # Protocolo de teletransporte
  └── main.py                  # Script de execução

docs/
  └── THEORY.md                # Fundamentos matemáticos
```

## Requisitos

- Python 3.9+
- Qiskit, Matplotlib, NumPy (veja requirements.txt)
